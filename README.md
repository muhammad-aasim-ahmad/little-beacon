# Little Beacon

A 15-minute browser survival builder. You play one stranded astronaut who mines four depths, refines an echo crystal and builds a distress beacon to be rescued.

**Play online:** https://YOUR-USERNAME.github.io/little-beacon/

It is built with vanilla JavaScript ES modules, Canvas 2D and native HTML controls. There is no build step, no server and no audio. Progress is saved in your browser; use **Export Save** to keep a copy.

Controls: **M** mine · **B** build · **E** eat · **R** rest · **Space** pause · **1/2** speed · **Esc** menu. Arrow keys and Enter work on the map.
